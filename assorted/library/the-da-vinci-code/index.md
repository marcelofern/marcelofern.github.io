"The only reason you read the Da Vinci Code book is to remember why you don't
read books like the Da Vinci Code". (Some critic somewhere).

I'm glad I didn't read a lot of reviews before reading the book as I think it
would have put me off entirely. So why did I pick this book?

Recently I have been trying to find some "light reading" books as I'm pretty
tired from work itself and the last thing I want after a long day is to read
some complicated text.

I remembered that growing up this book (and the movie) was all the rage. A lot
of Christian symbology so of course it did well!

The book is entertaining, it is fast paced and it also gave me a good list of
interesting places to visit in Europe.

Obviously, the ideas in these book seem super far-fetched and it is more for
entertainment than for real research!

I took a few quotes from the book, mostly so that I could have a list of things
(places) to look at after finishing the read.
