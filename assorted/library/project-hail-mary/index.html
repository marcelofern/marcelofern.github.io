Project Hail Mary

Created at: 2026-05-27

Quite a fun science fiction book. Good pacing and interesting ideas all around. The book is written in a very self-narrated way which makes it easier to get through. The movie is also a good adaptation. It lacks some of the details in the book but it is a pretty good summary if you don't want to read the whole book.
