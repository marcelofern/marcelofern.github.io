Scenes basics

Created at: 2026-07-06

Configuration

The first step is to set the model configuration for scenes so that their transitions aren't annoying.

Go to "Window" -> "Model Info" -> "Animation" and set the "Scene Transition" to 1.0 seconds and the "Scene Delay" to 0.0 seconds.

Adding a scene

First, copy the whole object you want to add a layer for, and then move it to a different location a few meters away from other objects.

  1. Go to "Window" -> "Scenes" and click the "+" icon to add a scene.
  2. Then go to the "Window" -> "Layers" and click the "+" icon to add a layer. Name the layer something descriptive.
  3. Go back to your object, select it and click with the right mouse button and select "Entity Info". In the "Layer" dropdown, select the layer you just created.
  4. Now only select the layer you are interested in your scene, and update it by right clicking on the scene tab and updating it. HOWEVER For whatever reason there is a bug here where you got to keep the layer0 radio button seleced, and then uncheck the ones you don't want to see, else the configuration does not save!
