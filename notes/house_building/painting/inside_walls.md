# Painting Inside Walls

```
Created at: 2026-04-18
```

List of tools for painting inside walls:

1. Roller and Roller Cover. Don't cheap out on a roller. You will notice very
   quickly that the roller you have is bad. A 230mm roller is good to start
   with and you should get the 270mm tray so you can use it with bigger rollers
   in future.
2. Paint Pan: This is where you put the paint. Sometimes you can buy a liner
   for the pan then you can throw away the liner which makes clean up much
   faster. A simple plastic bag might do the trick as way if you don't want to
   buy a liner.
3. Blue painters tape for the corners and edges.
4. Drop Cloth. Prefer a thick plastic sheet over porous cloth material.
5. 15-in-1-tool: Also known as a putty knife. This is to help remove paint
   excess and it also helps with cleaning the roller cover after you have used
   it. Also can be used as a hammer (from the bottom). Multi-use tool so worth
   having.
6. Good paintbrush: Have a cutting brush for finishings. Also get a good one
   that can last for years.
7. Extension pole: If you have a broom chances are that whatever roller you
   bought will fit with the broom cable. Else just get a cheap one. An
   adjustable pole 600 to 1200mm one will do the job. 
8. Sanding block and sand paper: Just get the cheapest.
9. A painters comb can help clean up the brushes afterwards but only buy it if
   you find it is cheap
