# Making an object unique

```
Created at: 2026-07-26
```

To make an object unique, select it by clicking on it **once** (else the option
won't show in the menu), and with the right click menu, select "Make Unique".
This will create a new instance of the object that can be modified
independently of the original.

Sometimes moving with a copy still makes the objects related, so you need to do
this to split them up.
