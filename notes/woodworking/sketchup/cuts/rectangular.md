# Cutting a rectangular object

```
Created at: 2026-07-06
```

Use the retangle tool (press "R") and just draw whatever rectangle you want.
Click to place the rectangle, and then using your number pad, change the
dimensions of the rectangle. You don't need to click on the lower right box to
change dimensions (it won't work) simple type in the number after clicking.

To add the 3rd dimension, use the "push/pull" tool (press "P") and click on the
rectangle. Move up/down to adjust the "thickness" and/or type in the number for
the thickness you want. Again, you don't have to select the measurement box at
the right bottom, simply type the number in after clicking on the shape.
