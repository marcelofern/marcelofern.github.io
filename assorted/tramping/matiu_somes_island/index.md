# Matiu/Somes Island

```
Created at: 2026-10-26
```

![photo0.jpg](photo0.jpg)

This is a very easy track for a weekend if you got some people visiting and you
want to show them a cool track on an island.

You can also spend the night on the island, there is plenty of accomodation
between the 3 different cottages that you can hire for the night at reasonable
prices.

There are gorgeous views of Wellington and Eastbourne.
