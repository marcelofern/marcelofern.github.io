# Replacing Chains

```
Created at: 2026-05-08
```

Everything you need to know about replacing a bike chain can be learned from
this video:

- https://www.youtube.com/watch?v=VdUQKVMPF5I

## Tips

- Keep your old chain as a reference so that you can size the new one correctly.
- If you use a connecting-rivet chain, make sure to have the proper tool to install it.
- Buy the tools from aliexpress, they are fairly cheap and there are a lot of
  high quality options.

## Notes to self

My shimano chain is for a 9-speed bike. I bought this chain:
- Shimano Chain 9s CN-HG93 116L which was perfectly sized so I didn't have to
  cut any links.
